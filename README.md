# Whisplet

Meeting copilot for Windows that runs on your own machine. Transcripts, speakers and notes stay local.
Private beta in preparation, autumn 2026.

This repository is the public companion: documentation, issue forms, discussions and release downloads.
The source lives in a private repository.

- Website: https://whisplet.ai
- Bugs and feature requests: Issues, through the forms
- Questions and ideas: Discussions
- Security reports: [SECURITY.md](SECURITY.md)
- Contact: hello@whisplet.ai

## Layout

- `site/` static website, deployed by Cloudflare Workers Builds from this repository
- `docs/` documentation (to come)
- `.github/` issue forms
