# Documentation

Start with [beta-guide.md](beta-guide.md) if you are a beta tester: what the beta is, how to
install it, where your data lives, and how to report a bug or send a crash report. For what
leaves your machine and when, see the site pages: [whisplet.ai](https://whisplet.ai),
[whisplet.ai/trust](https://whisplet.ai/trust), [whisplet.ai/privacy](https://whisplet.ai/privacy)
and [whisplet.ai/beta](https://whisplet.ai/beta). To report a security issue rather than a
regular bug, read [../SECURITY.md](../SECURITY.md) first.
